Microsoft Entra ID、Tenant 租戶登入 & Conditional Access

身分是新的安全邊界：Tenant 架構、跨租戶登入、Authentication、Authorization、SSO、MFA、Conditional Access

← 首頁 📖 30 天全詳解 ← Day 21 Day 23 →
🏢 Azure Tenant（租用戶）登入與架構必考重點：
• Tenant 定義：Microsoft Entra ID 的專屬信任實例，預設網域為 *.onmicrosoft.com，具備唯一 Tenant ID (GUID)。
• 一對多信任關係：1 個 Tenant 可關聯多個 Subscriptions；但 1 個 Subscription 同一時間只能信任 1 個 Tenant（若將訂用帳戶移轉至其他 Tenant，原有的 RBAC 角色指派會全部失效）。
• 跨租戶與 B2B 來賓登入：外部來賓（#EXT#）在原屬機構驗證身分，但在目標 Tenant 接受 RBAC 授權。Portal 需點選「切換目錄 (Switch directory)」，CLI 需使用 az login --tenant <TenantID/Domain>。
• 目錄角色 vs 資源角色：Entra Global Administrator 管身分目錄，預設不自動擁有所有 Subscription 的 RBAC 權限，需開啟「存取管理以取得 Azure 資源」提權開關。
